# DriftLabe — автосимулятор

Браузерный 3D-симулятор для проверки сцепления, аэродинамики, подвески и переноса нагрузки. Машина настроена на устойчивое grip-поведение; параметры можно менять прямо во время заезда. Тестовая трасса имеет четыре длинные прямые — примерно 640–700 м каждая.

## Запуск локально

```sh
cd app
npm install
npm run dev
```

Для проверки производственной сборки:

```sh
cd app
npm run build
```

## Управление

- `W` / `S` — газ / тормоз; `A` / `D` — руль.
- `Space` — ручник; `Shift` / `Ctrl` или `E` / `Q` — передачи.
- `R` — возврат на трассу; `C` — смена камеры; `M` — звук; `Esc` — пауза.
- Кнопка «Руль: клавиатура» переключает клавиатуру и мышь. Режим мыши использует фиксацию курсора (Pointer Lock); кнопка «Захватить курсор» повторно включает её после выхода через `Esc`.
- `F2` — консоль коэффициентов. Изменения применяются сразу; доступны сохранение, сброс и импорт/экспорт JSON.
- Во время заезда HUD показывает фактический угол поворота передних колёс.
- Полный каталог настроек, начальные значения, единицы и влияние на физику: [PARAMETERS.md](PARAMETERS.md). Проверки и описание модели: [PHYSICS_AUDIT.md](PHYSICS_AUDIT.md).

## Публикация на GitHub Pages

1. Скопируйте **содержимое этой папки** в корень репозитория, включая скрытую папку `.github`.
2. Отправьте файлы в ветку `main`.
3. В репозитории откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**. Это обязательная настройка; источник `Deploy from a branch` несовместим с этим workflow.
4. Workflow найдёт `package.json` со скриптом `build` в корне или вложенных папках, установит зависимости и соберёт сайт. Если такого скрипта нет, он опубликует статические файлы из папки с `index.html`.
5. `Build and Deploy DriftLabe` запустится при push в `main`; вручную его можно запустить через **Actions → Build and Deploy DriftLabe → Run workflow**.
6. После успешного завершения откройте **Actions → Build and Deploy DriftLabe → Summary** — там будет прямая ссылка `https://<owner>.github.io/<repo>/`.

Workflow автоматически использует имя репозитория как базовый путь Vite. Для собственного домена или репозитория `owner.github.io` URL может отличаться; откройте фактический адрес, показанный GitHub в **Settings → Pages**. Аудит физики и полный перечень настроек — в [PHYSICS_AUDIT.md](PHYSICS_AUDIT.md) и [PARAMETERS.md](PARAMETERS.md).
